# Guidelines & Rules

## Output Format & Token Optimization
- Be extremely concise in response text.
- Do NOT provide long summaries, explanations, or step-by-step breakdowns of modified files.
- State only what was changed in 1-2 brief sentences or bullet points.
- Do not repeat file contents back in the chat.

## Project Stack & Style
- Stack: React + Vite + Tailwind CSS v4
- Colors: Emerald `#1C352D`, Gold `#D4AF37`, Cream `#FDFBF7`
- Theme: Luxury, Elegant
